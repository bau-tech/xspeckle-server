# Third-party data in sections.json

`sections.json` is generated by `build_sections.py` from the two sources below.
Only cross-section dimensions (depth, flange width, web and flange thickness,
fillet radius; pipe outside diameter and wall) are taken, converted to metres.

## AISC shapes — steelpy

- Source: the `shape files/*_shapes.csv` of the `steelpy` Python package, version 1.1.1
  (https://pypi.org/project/steelpy/), by evanfaler.
- License: Apache License 2.0 (https://www.apache.org/licenses/LICENSE-2.0).
- Changes: dimensions only, converted from inches to metres; fillet radius derived as `k - tf`.

## European shapes — steelprofiles_api

- Source: `assets/{HEA,HEB,HEM,IPE,IPN,UPN}.csv` of
  https://github.com/timskovjacobsen/steelprofiles_api at commit
  `ceb131bd6c653cbd9e06279f61e69a2d0739ef25`.
